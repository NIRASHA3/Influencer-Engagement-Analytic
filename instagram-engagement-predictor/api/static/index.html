Prediction Workflow

The scoring engine follows a transparent pipeline so you can trace why confidence shifts and how the final value is produced.

1. Feature intake and sanitation Checks required fields, removes invalid numeric values, and standardizes category tokens.
2. Distribution-aware preprocessing Applies trained transformations so live inputs match the feature scale used during training.
3. Dual-model inference pass Runs XGBoost and Random Forest in parallel to produce independent engagement estimates.
4. Agreement and spread analysis Measures distance between models and classifies the result as tight, moderate, or divergent.
5. Feature influence explanation Ranks the strongest positive and negative drivers to support result interpretation.

Operational confidence bands

High confidence typically reflects aligned model outputs and in-range features. Lower confidence indicates model spread or feature drift and should trigger manual review.

  • Output packet: predicted rate, agreement score, and quality status
